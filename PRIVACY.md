# Privacy Policy

Chrome Site Blocker is designed to run locally in your browser.

## Data Stored

The extension stores these settings in Chrome extension storage:

- Whether blocking is enabled.
- The website rules you add to the block list.

When Chrome sync is enabled for extensions, Chrome may sync this extension data through your Google account according to your Chrome sync settings.

## Data Not Collected

This project does not:

- Collect analytics.
- Upload your block list to a developer server.
- Sell, share, or transfer user data.
- Read page content, form data, cookies, passwords, or messages.
- Use data for advertising.

## Permissions

The extension requests broad host access so it can block websites chosen by the user. It uses Chrome's `declarativeNetRequest` API so matching and redirects are handled by Chrome instead of by custom network interception code.

## Data Removal

You can remove stored data by deleting rules in the options page, clearing Chrome extension storage, or uninstalling the extension.
