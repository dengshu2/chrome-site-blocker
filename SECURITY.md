# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for sensitive security reports.

If this project is published under your GitHub account, add a private contact method here before release, such as a security email address or GitHub private vulnerability reporting.

Include:

- A clear description of the issue.
- Steps to reproduce it.
- The browser and extension version tested.
- Any impact you believe the issue may have.

## Scope

Security-sensitive areas include permission changes, rule generation, redirect behavior, stored block list handling, and release packaging.
